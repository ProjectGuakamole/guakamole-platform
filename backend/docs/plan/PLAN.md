## How this folder works

```
docs/plan/
  PLAN.md                                 this file (vision… + generated index)
  phase-NN-<slug>.md                      one per phase: title, goal, its tasks N.M
  phase-NN-<slug>/<N.M.K>-<slug>.md       one spec per subtask (micro-task)
```

- **Every phase exists from the start** with its title and goal, so the whole
  scope is visible and reviewed (roadmap gate).
- **One phase at a time**: phase N+1 gets its tasks and specs only when phase N
  is done (`make check` enforces it).
- **Status lives only in the subtask specs.** Task / phase status,
  `feature_list.json` and the index below are derived by `make plan`.
- Approved plans are **sealed**: editing what Codex approved (except `status`)
  fails `make check` until the gate approves the change.
- `make status` shows the whole plan, every gate verdict and the next step.

Ids: phase `NN` · task `N.M` · subtask `N.M.K`. They are used everywhere else
(`feature_list.json`, `progress/`, `docs/reference/<N.M.K>-<slug>.md`, commit
footer `Plan: docs/plan/phase-NN-<slug>/<N.M.K>-<slug>.md`).

### Subtask spec — `docs/plan/phase-01-users/1.1.1-email-value-object.md`

```markdown
# 1.1.1 Email value object
- status: pending
- layer: domain
- depends: none
- files:
  - src/<pkg>/domain/email.py          # crea: Email value object
- acceptance:
  - AC1 | rejects an address without '@' | tests/acceptance/test_1.1.1.py::test_ac1_no_at
  - AC2 | lowercases the domain | tests/acceptance/test_1.1.1.py::test_ac2_lower_domain

## Description
Immutable value object that validates and normalizes an email address…
```

- `status` ∈ `pending | in_progress | done | blocked`.
- `layer` ∈ `domain | application | infrastructure | interfaces`.
- `depends`: `none` or subtask ids (`1.1.1, 1.2.3`) that must be `done` first.
- `files:` the **1-3 production files under `src/`** it creates/modifies (the
  harness blocks writes outside them). Unit tests (`tests/unit/`) are not declared.
- `acceptance:` observable criteria, one test each; Codex writes those tests.
