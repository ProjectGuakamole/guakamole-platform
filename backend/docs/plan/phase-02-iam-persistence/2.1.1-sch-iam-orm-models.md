## Description
Cada módulo de dominio IAM tiene su propio `models.py` sobre la `Base` compartida;
entre todos mapean las once tablas de `sch_iam` (catálogos, geografía,
organizaciones, departamentos, usuarios y tokens revocados). Documentado en
`../docs/backend/backend-feature-iam-orm-alembic.md` y `../docs/backend/iam-er-diagram-sql.md`.
