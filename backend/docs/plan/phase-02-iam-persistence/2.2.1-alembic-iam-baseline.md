## Description
`iam_baseline` crea desde cero todo el esquema `sch_iam` solo con DDL (sin datos de
catálogo). `alembic/env.py` se niega a ejecutarse sin una conexión entregada por el
migrator, y `alembic.ini` no guarda credenciales.
Documentado en `../docs/backend/alembic/BACK-DB-MIGRATIONS-BASELINE.md`.
