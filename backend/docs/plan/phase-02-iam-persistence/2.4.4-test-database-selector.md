## Description
`get_test_database_url` solo devuelve una `TEST_DATABASE_URL` explícita que apunte a
un PostgreSQL local (loopback o socket Unix) cuyo nombre de base de datos termine en
`_test`. Documentado en `../docs/backend/alembic/BACK-DB-MIGRATIONS-BASELINE.md`.
