## Description
`get_engine` y `get_session_factory` están cacheados y se construyen a partir de
`Settings.database_url` con `hide_parameters=True`; `get_db_session` entrega una
sesión por petición y siempre la cierra. No hay un test unitario propio: la
evidencia es el test de integración HTTP de extremo a extremo que pasa por ella.
Documentado en `../docs/backend/backend-project-structure.md`.
