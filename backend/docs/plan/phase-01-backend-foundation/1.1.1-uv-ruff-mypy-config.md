## Description
`pyproject.toml` es la única fuente de dependencias y de configuración de
herramientas: uv con un `uv.lock` bloqueado, ruff (longitud de línea 88, conjuntos de
reglas A/ANN/ARG/B/C4/E/F/I/N/PT/RET/S/SIM/UP/W, formato con comillas dobles) y mypy
con `strict = true` sobre Python 3.12. `requirements.txt` se genera desde `uv.lock`
para el build de Docker. Documentado en `../docs/backend/backend-project-configuration.md`.
