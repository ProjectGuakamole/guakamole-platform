## Description
`api_v1_router` es el único punto de agregación de la API versionada: los routers de
los dominios se incluyen aquí y nunca se montan directamente sobre la app. Los tests
existentes protegen contra montajes duplicados de /api/v1, pero no rechazan un
segundo prefijo versionado (por ejemplo /api/v2), algo que queda fuera de esta
baseline. Documentado en `../docs/backend/backend-project-structure.md`.
