  - app/db/mixins.py        # TimestampMixin: create_at / update_at
- acceptance:
  - AC1 | la base declarativa compartida expone su metadata | tests/integration/test_iam_orm_preparation.py::test_base_metadata_is_available
  - AC2 | el mixin de timestamps mapea create_at y update_at como columnas con zona horaria | tests/integration/test_iam_orm_preparation.py::test_timestamp_mixin_maps_expected_columns

## Description
Todos los modelos ORM heredan de la `Base` compartida; `TimestampMixin` mapea
`created_at` / `updated_at` a las columnas `create_at` / `update_at`, con un valor
por defecto en servidor al crear. Documentado en `../docs/backend/backend-feature-iam-orm-alembic.md`.
