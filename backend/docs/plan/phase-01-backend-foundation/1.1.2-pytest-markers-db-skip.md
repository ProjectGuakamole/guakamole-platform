## Description
Pytest se ejecuta con `--strict-config --strict-markers` y un catálogo cerrado de
markers (`test_unit`, `integration`, `db`, `security`, `architecture`, `slow`).
`tests/conftest.py` omite todos los tests `db`/`integration` salvo que haya una
`TEST_DATABASE_URL` explícita, y reinicia las cachés de settings y del rate limiter
alrededor de cada test. Documentado en `../docs/backend/ci-strategy.md`.
