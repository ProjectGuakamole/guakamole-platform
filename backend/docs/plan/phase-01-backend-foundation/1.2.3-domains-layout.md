## Description
El código de negocio vive en `app/domains/<domain>/<module>/` (por ejemplo
`app/domains/iam/users/`), con `__init__.py` mínimos y nombres de paquete de capa en
plural. Documentado en `docs/architecture.md` y `../docs/backend/backend-project-structure.md`.
