# Project-Guakamole

## El proyecto se escribirá en Castellano.

## Misión

> Project Guakamole MVP 0.1 es una plataforma B2B de entrenamiento en ciberseguridad que permite a una organización gestionar equipos, asignar itinerarios y escenarios prácticos, ejecutar laboratorios SOC individuales y temporales, monitorizar el progreso y auditar la actividad realizada.
